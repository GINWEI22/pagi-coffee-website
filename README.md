# Pagi Coffee – Responsive Café Website

A single-page responsive website for a neighbourhood café. Built as a portfolio sample for small business clients.

**Live demo:** https://pagi-coffee-demo.netlify.app

## Features
- Mobile-first responsive layout
- Menu with prices
- Opening hours and contact details
- WhatsApp order button
- Embedded Google Map

## Tech
HTML, CSS, deployed on Netlify
